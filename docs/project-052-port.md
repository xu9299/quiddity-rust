# Project overlay on 0.5.2

This branch merges the official 0.5.2 source with the previously validated serial
project overlay. Official recognition, schemas, independent mass convergence,
ray-cache repair checks, evidence source-refusal tests and recess controls remain.
The release already includes shared ray geometry, exact NURBS operand reuse,
physical evidence serialization reuse, recess discovery reuse and volume refusal
prefixes; those implementations are merged rather than applied a second time.

The overlay retains document-only recognition, optional native timing, exact
quadrature prefix reuse, prismatic-pair eligibility checks and original-slab
rejection witnesses. All geometry work stays on the calling thread. Independent
part scheduling belongs to the host application. A partial volume integral can
reject but never establish acceptance.

This source is the project baseline for a separate NURBS isocurve evaluator
candidate. Both native files must use the same Windows toolchain and compiler
flags. Timings from different release baselines or the historical parallel kernel
are not a comparison for that candidate. No runtime is selected by this document.
